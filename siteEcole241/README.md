# Nom du projet : ***SITE WEB ÉCOLE 241***

## Description : Il s'agit d'un projet de classe visant à appliquer l'ensemble des techniques et bonnes pratiques appris pendant la formation notament 
- structurer correctement une page avec HTML5, 
- utiliser des balises sémantiques, Organiser un projet web,
- créer une interface moderne avec CSS3, 
- utiliser Flexbox ou grid, 
- rendre un site responsive, 
- respecter une cohérence visuelle, 
- produire un code propre et lisible, 
- utiliser Git et Github pour le versionnement etc. 
afin de réaliser un projet d'intégration.

## Les technologies utilisées :
Pour se projet, les technologies utilisées sont :
Les langages **HTML5**, **CSS3** et **JavaScript** pour assurer respectivement la structure, le style et le dynamisme de la page.

- Les **outils** sont :
**Vite**, pour l'initiasation et la création du projet
**Git et Github** pour le versionnement
**VS Code** comme environnement de développment.
